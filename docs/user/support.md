## Community

- **Discussions:** repository Discussions tab for usage questions

## Security

**Do not open public issues for vulnerabilities.**

Use [GitHub Private Vulnerability Reporting](https://github.com/stribog-cloud/KubeVigil/security) per `SECURITY.md`.

Expected response: acknowledgement within 48 hours.

## Maintainer escalation

If an issue is blocked or security-sensitive after private report, maintainers listed in `CODEOWNERS` (`@msambare`) coordinate resolution and release.
